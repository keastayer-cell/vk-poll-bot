# vk-poll-bot

Отдельный VK-бот для автоматических голосований в беседе «ФК Ушаково».

Проект намеренно не связан с `tg-poll-bot`: у него собственные зависимости,
конфигурация, состояние и процесс запуска.

## Статус

Создан базовый каркас. Следующий этап — подключение сообщества VK через Bots Long
Poll API и реализация голосования кнопками «ДА» / «Нет».

Расписание по умолчанию: понедельник и четверг, 08:00 по Москве.

## Локальный запуск тестов

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/pytest
```

## Конфигурация

Скопируйте `.env.example` в `.env`. Никогда не публикуйте `VK_GROUP_TOKEN`.
