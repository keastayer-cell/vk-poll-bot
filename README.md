# vk-poll-bot

Отдельный бот сообщества VK для автоматических голосований в беседе «ФК Ушаково».
Проект не зависит от `tg-poll-bot`: у него собственные зависимости, конфигурация,
состояние, тесты и процесс запуска.

## Возможности

- интерактивные кнопки «ДА» и «Нет»;
- изменение ранее выбранного варианта;
- отображение имён проголосовавших;
- сообщения `+1 Фамилия` и компактная форма `+1Фамилия`;
- админские `/plus1`, `/minus1`, `/poll`, `/close`;
- `/status`, `/where`, `/help`;
- уведомления при 9 и 10 участниках и при последующей потере кворума;
- дедлайн-уведомление администраторам;
- напоминание об игре, если кворум набран;
- автоматическое закрытие и открепление опроса;
- изменение расписания через `/settime` и `/setdays`;
- объявления через личные сообщения боту: `/announce`, следующий текст, `/cancel`;
- сохранение состояния и восстановление после перезапуска;
- повторное подключение к Bots Long Poll после сетевых ошибок.

Расписание по умолчанию: понедельник и четверг, запуск в 08:00 МСК, дедлайн
в 15:00, напоминание в 19:00 и закрытие в 20:00. Все времена настраиваются.

## Подготовка сообщества VK

1. Включить сообщения сообщества и возможности ботов.
2. Включить «Разрешать добавлять сообщество в чаты».
3. Добавить сообщество в тестовую беседу.
4. В «Работа с API» создать ключ с доступом к сообщениям сообщества.
5. Включить Bots Long Poll API.
6. В типах событий включить «Входящие сообщения» и «События действий с клавиатурой».

Ключ сообщества нельзя публиковать или присылать в чат.

## Установка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
cp .env.example .env
```

Заполните в `.env` как минимум `VK_GROUP_TOKEN`, `VK_GROUP_ID` и `ADMIN_IDS`.
На первом запуске можно оставить `VK_PEER_ID=0`.

## Первый запуск в тестовом чате

```bash
.venv/bin/python main.py
```

Отправьте в тестовый чат `/where`. Бот ответит двумя числами:

```text
peer_id=2000000001
user_id=123456
```

Запишите `peer_id` в `VK_PEER_ID`, а свой `user_id` — в `ADMIN_IDS`, перезапустите
бота и отправьте `/poll`. Пока `ENABLE_SCHEDULER=0`, автоматические задания отключены.

## Проверки

```bash
.venv/bin/python main.py --check
.venv/bin/pytest
.venv/bin/ruff check .
```

## Команды

```text
/poll                         запустить опрос вручную (админ)
/close                        закрыть опрос (админ)
/status                       показать голоса и имена
/plus1 Фамилия                добавить приглашённого (админ)
/minus1 [Фамилия]             убрать приглашённого (админ)
+1 Фамилия                    добавить приглашённого (любой участник)
-1                            убрать последнего приглашённого (админ)
/settime                      показать расписание
/settime poll 08:00           изменить время запуска
/settime deadline 15:00       изменить дедлайн
/settime reminder 19:00       изменить напоминание
/settime close 20:00          изменить закрытие
/setdays poll mon,thu         изменить дни запуска
/announce                     начать ввод объявления (админ)
/cancel                       отменить ввод объявления
/where                        показать ID беседы и пользователя
```

После проверки в тестовой беседе установите `ENABLE_SCHEDULER=1`.
